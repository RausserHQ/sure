# Domain docs

Engineering skills read domain documentation before exploring relevant code.

## Read before exploring

- Read root `CONTEXT.md` when it exists.
- Read relevant decisions in `docs/adr/` when they exist.
- If these files do not exist, proceed. Create them when domain terms or decisions are resolved, using the domain-modeling skill.

## Layout

This is a single-context repo: one root `CONTEXT.md` and root `docs/adr/`.

## Vocabulary and decisions

Use terms defined in `CONTEXT.md` in issues, proposals, hypotheses, and tests. Flag a conflict with an existing ADR explicitly.
